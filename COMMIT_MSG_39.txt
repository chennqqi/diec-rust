1. const→var preprocessing in eval_script and evaluate_rule_source:
   Qt Script treats const like var (function-scoped, redeclarable).
   QuickJS rejects redefinition, causing SyntaxError in rules like
   Nintendo-certified-file.1.sg. Replacing const with var is safe
   because upstream rules don't rely on const immutability.

     isNetGlobalCctorPresent
   - Debug: getNumberOfDebugDataRecords, getDebugDataOffset/Size/Type
   - Rich: getNumberOfRichIDs, getRichID, getRichCount
   - File: getFileDirectory, getFileBaseName, getFileCompleteSuffix

   - Validation: isEntryPointCorrect, isHeaderCorrect, etc.
   - Address: OffsetToRVA, VAToOffset, RVAToOffset

3. Fix read_codePageString parameter type:
   Third parameter changed from Option<i32> to Option<String>
   to accept code page names like 'SJIS', 'CP1251'.
