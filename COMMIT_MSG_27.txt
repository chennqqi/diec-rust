phase4: directory recursive scanning

Fifth step of Phase 4 (CLI). Add --recursive/-r flag for directory
scanning, with sorted file collection for deterministic output.

CLI changes:
- New --recursive/-r flag enables recursive directory scanning
- expand_target: expands directories into file lists
  - Directory + --recursive: collect all files recursively
  - Directory without --recursive: error "is a directory"
  - Non-existent path: error "path not found"
  - Empty file list: exit code 4 (EXIT_INPUT)
- collect_files: recursively collects regular files, sorted by
  name for deterministic output order
